# sbtun

轻量级 sing-box TUN 客户端。

## 项目定位

让普通用户不用理解 sing-box、TUN、DNS 和路由规则，也能通过导入节点/订阅，一键建立稳定的 TUN 网络，并获得正确的流量分流体验。

## 当前技术路线

- Go：核心控制层
- Wails：桌面 GUI（下一阶段接入）
- sing-box：代理、TUN、DNS 与路由核心
- Windows：第一目标平台
- 用户配置与 sing-box runtime 配置严格分离

## 路由模式

1. 智能分流
2. 全局代理
3. 全局直连
4. 自定义规则

## 已完成的核心能力

- 用户配置持久化与原子保存
- 用户配置校验
- sing-box runtime 配置自动生成
- sing-box 自带配置校验闭环
- sing-box 进程退出监控
- TUN 状态只在真实启动流程验证后标记为运行
- 启动失败自动回滚状态
- DNS 自动 / 系统 / 自定义模式基础模型
- 智能分流规则集基础接入
- 中文路由模式预设
- 自定义路由规则模型

## 重要设计原则

**绝不伪造“已连接”。**

TUN 启动流程必须经过：

```text
用户点击启动
  ↓
检查配置
  ↓
生成 runtime 配置
  ↓
sing-box check
  ↓
启动 sing-box
  ↓
等待并验证 TUN / DNS / 网络可用性
  ↓
验证成功
  ↓
才显示「运行中」
```

如果任一步失败，必须进入错误状态并执行清理/恢复，而不是让界面显示假连接。

## 开发原则

代码从 0 开始，不 Fork 其他客户端；成熟能力优先复用官方核心和稳定组件，不重复实现 sing-box 已经解决的问题。
